# 🌿 MoodWords｜心情英文日記 使用說明書

**把每天的心情，變成一個英文單字！**

MoodWords 是一個結合日記與 AI 英文學習的小工具。使用者可以記錄每天的生活與心情，讓 AI 根據日記內容推薦適合的英文單字。

### 1. 每天可以寫很多篇日記 ✏️
- 每天可以新增多篇日記，不限一篇。
- 支援中文或英文輸入。
- 當天的日記可以編輯或刪除。
- AI 會綜合當天所有日記內容，推薦符合當日心情的英文單字。

### 2. 每天只能收藏一個英文單字 ♡
- AI 每天會推薦一個英文單字，包含中文意思、音標、例句及推薦理由。
- **收藏前可以重新推薦，收藏後就不能更換。**
- 每個日期最多只能收藏一個單字。
- 可以透過日記月曆回顧過去收藏的單字。

### 3. 必須使用同一個瀏覽器才能保留紀錄 💾
- 日記和收藏單字會自動儲存在目前使用的瀏覽器中。
- **必須使用同一台裝置、同一個瀏覽器，才能看到之前的紀錄。**
- 換手機、換電腦或換瀏覽器，資料不會自動同步。
- 建議定期使用「設定與備份」中的匯出功能保存資料。

### 4. 如何開始使用？
1. 開啟 MoodWords 網站。
2. 在「今日心情」輸入日記並儲存。
3. 點擊「推薦今日單字」，查看 AI 推薦結果。
4. 喜歡這個單字就按「收藏今日單字」。
5. 進入「日記月曆」，回顧每天的心情與英文單字。

**網站連結：** https://moodwords-diary.pages.dev
